# Artificial Intelligence

This repository contains my coursework for the **Artificial Intelligence** course, including laboratory work, assignments, implementations, and exercises covering fundamental and advanced AI concepts.

## Course Topics

The course covered a broad range of topics in Artificial Intelligence, including:

* **Introduction to Artificial Intelligence**

  * AI fundamentals and intelligent agents
  * Problem formulation and state-space representation

* **Search Algorithms**

  * Uninformed search
  * Informed search
  * Heuristic search
  * Search strategies and problem solving

* **Symbolic Artificial Intelligence**

  * Knowledge representation
  * Reasoning and inference
  * Rule-based systems

* **Logic and Inference**

  * Propositional Logic
  * First-Order Logic
  * Logical inference and reasoning

* **Probability in AI**

  * Probability concepts for uncertain reasoning
  * Conditional probability
  * Bayesian reasoning

* **Bayesian Networks**

  * Probabilistic graphical models
  * Conditional dependencies
  * Inference using Bayesian Networks

* **Markov Models**

  * Markov processes
  * Probabilistic state transitions
  * Applications of Markov models in AI

* **Optimization and Local Search**

  * Optimization techniques
  * Local search algorithms
  * Hill climbing and related approaches

* **Constraint Satisfaction Problems**

  * Constraint modeling
  * Backtracking search
  * Constraint-based problem solving

* **Machine Learning**

  * Introduction to Machine Learning
  * Supervised Learning
  * Unsupervised Learning
  * Reinforcement Learning
